    ♻️Cycle d'économie circulaire — Sens des flux

    L'eau du marigot Yangana collecte les fientes du poulailler et alimente les bassins 1 et 2 — l'eau pré-fertilisée fait pousser le phytoplancton dont se nourrissent les poissons. À la vidange périodique des bassins, les boues vont vers le compost. Y arrivent aussi le lisier des porcs et le fumier des cabris. Tout est mélangé pendant 45 jours, puis distribué comme engrais NPK vers les champs et les cultures.

    Lance un déploiement complet en une commande. Chaque étape est tracée avec horodatage et durée. Tous les artefacts sont sauvegardés dans un dossier dédié.

    🚀Lancer un déploiement complet

    L'assistant enchaîne automatiquement les 9 étapes du déploiement : backup BDD, git pull, build & reload backend, build & upload frontend Cloudflare, tests post-déploiement. Durée estimée : 4–6 minutes.

    Pré-requis : les commits à déployer doivent déjà être poussés sur origin/main. Le serveur fait git pull --ff-only sans rebase.
